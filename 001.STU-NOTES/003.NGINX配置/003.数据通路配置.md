## 1. sendfile:本地文件的零拷贝

```
指令生效   ngx_http_core_module.c:1341-1345(关闭时置 r->connection->sendfile = 0)
Linux 实现 ngx_linux_sendfile_chain             src/os/unix/ngx_linux_sendfile_chain.c:50

传统 read()+write():
  磁盘 ──DMA──► 页缓存 ──CPU拷贝──► 用户缓冲 ──CPU拷贝──► socket缓冲 ──DMA──► 网卡
  4 次拷贝、4 次用户/内核切换、2 次系统调用

sendfile():
  磁盘 ──DMA──► 页缓存 ──CPU拷贝──► socket缓冲 ──DMA──► 网卡
  2 次拷贝、数据全程不进用户态、1 次系统调用
```

**边界**:只对**本地文件**的响应生效;反向代理响应体在内存缓冲里,走 writev,
sendfile 不参与(调了也无感)。NFS / FUSE 等网络文件系统上 sendfile 可能更慢。

## 2. tcp_nopush 与 tcp_nodelay:同一连接的不同时机

两个开关看似矛盾(Cork 攒包 vs 立即发小包),源码里作用于**不同阶段**:

```
 一条连接的两种发送形态(两个开关可以同时 on):

 ── 文件响应:走 Cork(攒包,省包数/带宽)──────────────────────
   开始发文件   src/os/unix/ngx_linux_sendfile_chain.c:136
                ngx_tcp_nopush(c->fd) = setsockopt(TCP_CORK)
                → 响应头 + 文件首块攒成一个整包
   发送完毕     request.c:3438  ngx_tcp_push(c->fd) 拔塞,整包放行
   之后         request.c:3445-3451  tcp_nodelay 接管后续小包

 ── API / 小响应:走 NODELAY(不等,保延迟)────────────────────
   首个请求     request.c:767  ngx_tcp_nodelay(c)
                = setsockopt(TCP_NODELAY)(ngx_connection.c:1566-1568)
                Nagle 会把未确认小包后的数据攒到 ACK——交互式 API 被加一个
                RTT 级延迟;NODELAY 让小包立即发出
```

```
tcp_nopush   未开启时:request.c 侧直接置 NGX_TCP_NOPUSH_DISABLED(ngx_http_core_module.c:1397-1399)
tcp_nodelay  默认已是 1(:3895),显式写只为可读性
平台细节     FreeBSD / Darwin 上两选项互斥,nginx 用全局标志
             ngx_tcp_nodelay_and_tcp_nopush 处理(src/os/unix/ngx_posix_init.c:16);
             Linux 无此限制,标准搭配:sendfile on; tcp_nopush on; tcp_nodelay on;
```

## 3. open_file_cache:省掉每请求的 open+stat

```
open_file_cache max=10000 inactive=60s;
open_file_cache_valid 60s;        revalidate 周期
open_file_cache_min_uses 2;       inactive 窗口内使用次数门槛,淘汰冷文件
open_file_cache_errors on;        缓存打开失败(防穿透)
```

以路径为 key 缓存 fd 与 stat 结果(大小/mtime)。对静态站,每请求两次系统调用
(open + 各级目录 stat)直接归零;目录也会被缓存。

## 4. aio threads:大文件别拖住事件循环

页缓存未命中时 sendfile 仍阻塞在磁盘读,而 worker 是单线程——一个大文件慢读,
整个 worker 上的全部连接都停摆。`aio threads;` 把读取丢进线程池:

```
worker 事件循环 ──ngx_thread_task_post──► 任务队列 ─► 线程组(默认 32 线程,
      ▲                                       │        max_queue 65536,
      │ 完成事件回到 epoll                     │        ngx_thread_pool.c:439-440)
      └──────────────────────────────── 阻塞读挪出去,主循环永不阻塞
```

配合 `directio`(绕过页缓存,避免大文件冲刷热点缓存)是大文件高并发的标准组合。
